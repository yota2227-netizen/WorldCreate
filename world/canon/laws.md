# 根本原理：記憶の世界（レスモネの三則）
1. **存在の則**：あらゆるものは、世界に覚えられていることで存在を保つ。忘れられたものは、名前・意味・用途の順に失われ、最後に形が崩れていく。
2. **余韻の則**：出来事が起きると、その大きさに見合った「余韻」があとに残る。余韻はこの世界の魔力であり、世界をつなぎとめる力でもある。
3. **代償の則**：余韻は、それを生んだ元の出来事と目に見えないつながりを持つ。余韻を使うと、元の出来事の記憶が薄れる。代償のない魔法はない。

# 余韻（魔力）の性質
- 出来事が大きいほど余韻は濃い（誕生・死・誓い・別離・大災害・大きな火や水の動き）。ささいな出来事の余韻は数日で消える。
- **減り方**：余韻は約29日（留め月の一周期）ごとに半分になる。ただし地中に沈むと減らなくなり、ほぼいつまでも残る。
- **濃さ**：出来事が積み重なった場所ほど魔力が濃い。濃い場所では物が不安定になる（石が揺らぎ、形がゆがみ、距離が伸び縮みする）。出来事の少ない場所は固く静かで、魔力も薄い。
- **沈殿**：古い余韻は地中に降り積もり、「憶石（おくせき）」という結晶になる。憶石は出来事の記憶が固まった石で、魔力の蓄えや燃料になる。
- **原余韻（げんよいん）**：世界で最初の出来事「最初の一打」の余韻。世界全体に薄く満ちていて、決して尽きない。これが世界の最低限の魔力であり、物がすぐには消えない理由でもある。

# 魔法の働き方と限界
- **余韻を汲む**：術者は余韻に手を差し入れ、必要な分をすくい取って現象に変える（火を起こす、傷をふさぐ、物を動かすなど）。
- **代償**：汲まれた余韻の元になった出来事は、記憶が薄れる。物としての結果は残るが、その証拠・名前・意味・感情が失われていく。（例：戦場の余韻を汲めば、その戦いは語り継がれても、実感を失う）
- **自分の体験**：自分自身の体験の余韻はもっとも汲みやすく、効率もよい。そのかわり、術者自身の記憶が失われる。
- **汲み尽くすこと**：ひとつの出来事の余韻をすべて汲み尽くすと、その出来事は世界から忘れられる。その出来事から生まれた物も、忘れられたものとして形を失いはじめる。
- 一度に汲める量は、術者の「器」（その人が持つ記憶や体験の厚み）で決まる。器の小さい者は大きな余韻を受け止められず、あふれた余韻に内側から揺さぶられる。
- 魔法は、すでに起きたことの余韻しか使えない。一度も起きたことのない現象は、どれほど望んでも起こせない。

# 余韻の五相（出来事の種類による分け方）
この世界には「物質の元素」がない。物の性質は、そこに積もった余韻の「相（そう）」で決まる。
- **灼（しゃく）**：火・熱・はじける出来事。軽く、ほどき月で散りやすい。沈みにくい。憶石は赤橙色で、触れると温かい。
- **流（りゅう）**：水・風・移動の出来事。重さは中くらい。流れた先にたまりやすい。憶石は青灰色で、表面がいつも湿っている。
- **結（けつ）**：誓い・建築・結びつきの出来事。もっとも沈みやすく、減りにくい。憶石は白く硬い。
- **別（べつ）**：死・別離・裂ける出来事。重く、冷たい。沈みやすい。憶石は黒く、まわりの音を吸い込む。
- **生（しょう）**：誕生・成長の出来事。重さは中くらい。濃い場所では物の形が変わりやすい。憶石は緑色で、ゆっくりふくらむ。
- 沈みやすさの目安（留め月への反応）：結0.9／別0.8／生0.6／流0.5／灼0.3。散りやすさはおおむねその逆。
- **相の一致**：汲む余韻の相と、起こす現象の相は同じでなければならない。癒しには生、火には灼、橋を架けるには結の余韻が要る。別の余韻から癒しは生まれない。
- **濁り（にごり）**：いくつもの相が混ざった余韻。使い道は広いが、扱いが難しい。
- **無色の余韻**：創世のころの余韻は、最初の一打が五相すべてを含んでいたため、まだ相に分かれていない。大地や生き物が生まれて出来事の種類が増えるにつれ、相に分かれていく。

# 忘れられていく仕組み
- **記憶度（きおくど）**：ものが世界に覚えられている度合いを「記憶度」という。十分に覚えられていれば1、完全に忘れられれば0。
- **憶縁（おくえん）**：ものを世界につなぎとめる縁。そのものを知る者、残された痕跡、元の出来事とつながる余韻がこれにあたる。憶縁が一つでも残っているあいだは、記憶度は1のまま保たれる。
- **憶縁を失ったとき**：記憶度は約29日ごとに半分になる。
- **失われる順番**
  1. 名前が失われる：記憶度0.5以下（約29日後）
  2. 意味が失われる：0.25以下（約58日後）
  3. 用途が失われる：0.125以下（約87日後）
  4. 形が崩れはじめる：1/1024以下（約290日後）
- **形が長く残る理由**：原余韻が世界全体で物を最低限支えているため、名前・意味・用途が失われても、形は一年近く残る。ただし原余韻は記憶度を回復させず、忘れられていく流れも止めない。
- **汲み尽くした場合**：出来事の余韻を汲み尽くすと、その出来事は憶縁を失い、そこから生まれた物も忘れられはじめる。
- **ふたたび覚えられた場合**：憶縁が戻れば、忘れられていく流れは止まる。ただし、一度失われた名前や意味は、元どおりには戻らないことがある。

# 反復の余韻：常余韻（じょうよいん）
- 毎日・毎周期くり返される出来事は、一回ごとの余韻は小さいが、同じ形の余韻が重なり続ける。
- 毎日1単位ずつ加わり、毎日 2^(-1/29)（約0.976）倍に薄れるので、量は一日分のおよそ42倍で落ち着く（立ち上がりは約29日で半分、約87日で約9割に達する）。
- これを「常余韻」と呼ぶ。大事件の余韻より薄いが、決して涸れず、原余韻に次いで世界を満たす安定した魔力。
- 常灯の常余韻は、熱（灼）と移動（流）の出来事を含むため、灼・流の性質がおもに強い。ほどき月・留め月の満ち欠けも周期的な出来事で、同様の常余韻を生む。
- 汲んで元の出来事の記憶が薄れても、毎日新しい出来事が起きて余韻が補われるため、常余韻は汲み尽くせない（原余韻ほど無尽蔵ではなく、一度に大量に汲めば一時的に薄くなるだけ）。
- 毎日起きる出来事は毎日誰かの目に触れるため、憶縁を失わない。くり返されるものは忘れられにくい。
- 繰り返しが途絶えた場合（灯が昇らない日が生じた場合など）、常余韻は29日ごとに半分に薄れていく。
