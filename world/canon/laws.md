# 根本原理：記憶の世界（レスモネの三則）
1. **存在の則**：万物は「世界に覚えられている」ことで存在を保つ。覚えられなくなったものは形が緩み、意味・名・用途から先に剥がれ、最後に物質が薄れる。
2. **余韻の則**：出来事が起きると、その大きさ（重さ）に比例した「余韻」が残る。余韻こそがこの世界の魔力であり、世界を縒り合わせる糸でもある。
3. **取引の則**：余韻は必ず「元の出来事」と見えない糸で繋がっている。余韻を使えば元の出来事の痕跡が薄れる。代償なしの魔法はない。

# 余韻（魔力）の性質
- 出来事が大きいほど余韻は濃い（誕生・死・誓い・別離・大災害・大きな火や水の動き）。些細な出来事の余韻は数日で消える。
- **減衰**：余韻は約29日（留め月の一周期）ごとに半減する。ただし地に「沈殿」すると減衰は止まり、ほぼ永久に残る。
- **濃淡**：出来事が積み重なった場所ほど魔力が濃い。濃い場所では物質が不安定（石が揺らぎ、形が緩み、距離が伸縮する）。出来事のない場所は固く、静かで、魔力が薄い。
- **沈殿**：古い余韻は地中に降り積もり「憶石（おくせき）」となる。憶石は出来事の記憶を結晶にしたもので、魔力の貯蔵庫・燃料になる。
- **原余韻**：世界最初の出来事「最初の一打」の余韻は、背景として全世界に薄く、決して枯れずに満ちている。これが世界の最低限の魔力で、物がすぐに消えない理由である。

# 魔法の働き方と限界
- **汲む**：術者は余韻に手を差し入れ、必要な分を汲み取って現象に変える（火を起こす、傷を塞ぐ、物を動かす等）。
- **痩せ**：汲まれた余韻の元の出来事は「痩せる」。物質的な結果は残るが、その証拠・名・意味・感情が薄れる。（例：戦場の余韻を汲めば、その戦いは語られても実感を失う）
- **自己の出来事**：自分自身の体験の余韻は最も汲みやすく効率が高いが、代償として術者自身の記憶が失われる。
- **汲み尽くし**：ひとつの出来事を汲み尽くすと、その出来事は世界から「覚えられていない」ものとなり、結果として生じた物も形を緩めはじめる。
- 汲める量の上限は術者の「器」（自分の記憶・体験の厚み）による。空っぽの器には大きな余韻は入らず、溢れた余韻は術者を内側から揺らがせる。
- 魔法は「既に起きたことの余韻」しか使えない。起きたことのない現象は、どれほど望んでも起こせない。
