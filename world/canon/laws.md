# 根本原理：記憶の世界（レスモネの三則）
1. **存在の則**：あらゆるものは、世界に覚えられていることで存在を保つ。忘れられたものは、名前・意味・用途の順に失われ、最後に形が崩れていく。
2. **余韻の則**：出来事が起きると、その大きさに見合った「余韻」があとに残る。余韻はこの世界の魔力であり、世界をつなぎとめる力でもある。
3. **代償の則**：余韻は、それを生んだ元の出来事と「引き綱（ひきづな）」でつながっている。余韻を汲むと綱が引かれ、元の出来事の記憶が薄れる。代償のない魔法はない（詳しくは「引き綱と代償」）。

# 余韻（魔力）の性質
- 出来事が大きいほど余韻は濃い（誕生・死・誓い・別離・大災害・大きな火や水の動き）。ささいな出来事の余韻は数日で消える。
- **減り方**：余韻は約29日（留め月の一周期）ごとに半分になる。ただし地中に沈むと減らなくなり、ほぼいつまでも残る。
- **濃さ**：出来事が積み重なった場所ほど魔力が濃い。濃い場所では物が不安定になる（石が揺らぎ、形がゆがみ、距離が伸び縮みする）。出来事の少ない場所は固く静かで、魔力も薄い。
- **沈殿**：古い余韻は地中に降り積もり、「憶石（おくせき）」という結晶になる。憶石は出来事の記憶が固まった石で、魔力の蓄えや燃料になる。
- **原余韻（げんよいん）**：世界で最初の出来事「最初の一打」の余韻。世界全体に薄く満ちていて、決して尽きない。これが世界の最低限の魔力であり、物がすぐには消えない理由でもある。

# 魔法の働き方と限界
- **余韻を汲む**：術者は余韻に手を差し入れ、必要な分をすくい取って現象に変える（火を起こす、傷をふさぐ、物を動かすなど）。
- **代償**：汲まれた余韻の元になった出来事は、それを知るすべての者のあいだで記憶が薄れる（「引き綱と代償」を参照）。物としての結果は残るが、感情・経緯・名前・意味が失われていく。（例：戦場の余韻を汲めば、その戦いは語り継がれても、実感を失う）
- **自分の体験**：自分自身の体験の余韻はもっとも汲みやすく、効率もよい。そのかわり、術者自身の記憶が失われる。
- **汲み尽くすこと**：ひとつの出来事の余韻をすべて汲み尽くすと、その出来事は世界から忘れられ、「抜け跡（ぬけあと）」だけが残る。その出来事から生まれた物も、忘れられたものとして形を失いはじめる。
- 一度に汲める量は、術者の「器」（その人が持つ記憶や体験の厚み）で決まる。器の小さい者は大きな余韻を受け止められず、あふれた余韻に内側から揺さぶられる。
- 魔法は、すでに起きたことの余韻しか使えない。一度も起きたことのない現象は、どれほど望んでも起こせない。

# 余韻の五相（出来事の種類による分け方）
この世界には「物質の元素」がない。物の性質は、そこに積もった余韻の「相（そう）」で決まる。
- **灼（しゃく）**：火・熱・はじける出来事。軽く、ほどき月で散りやすい。沈みにくい。憶石は赤橙色で、触れると温かい。
- **流（りゅう）**：水・風・移動の出来事。重さは中くらい。流れた先にたまりやすい。憶石は青灰色で、表面がいつも湿っている。
- **結（けつ）**：誓い・建築・結びつきの出来事。もっとも沈みやすく、減りにくい。憶石は白く硬い。
- **別（べつ）**：死・別離・裂ける出来事。重く、冷たい。沈みやすい。憶石は黒く、まわりの音を吸い込む。
- **生（しょう）**：誕生・成長の出来事。重さは中くらい。濃い場所では物の形が変わりやすい。憶石は緑色で、ゆっくりふくらむ。
- 沈みやすさの目安（留め月への反応）：結0.9／別0.8／生0.6／流0.5／灼0.3。散りやすさはおおむねその逆。
- **相の一致**：汲む余韻の相と、起こす現象の相は同じでなければならない。癒しには生、火には灼、橋を架けるには結の余韻が要る。別の余韻から癒しは生まれない。
- **濁り（にごり）**：いくつもの相が混ざった余韻。使い道は広いが、扱いが難しい。
- **無色の余韻**：創世のころの余韻は、最初の一打が五相すべてを含んでいたため、まだ相に分かれていない。大地や生き物が生まれて出来事の種類が増えるにつれ、相に分かれていく。

# 忘れられていく仕組み
- **記憶度（きおくど）**：ものが世界に覚えられている度合いを「記憶度」という。十分に覚えられていれば1、完全に忘れられれば0。
- **憶縁（おくえん）**：ものを世界につなぎとめる縁。そのものを知る者、残された痕跡、元の出来事とつながる余韻がこれにあたる。憶縁が一つでも残っているあいだは、記憶度は1のまま保たれる。
- **憶縁を失ったとき**：記憶度は約29日ごとに半分になる。
- **失われる順番**
  1. 名前が失われる：記憶度0.5以下（約29日後）
  2. 意味が失われる：0.25以下（約58日後）
  3. 用途が失われる：0.125以下（約87日後）
  4. 形が崩れはじめる：1/1024以下（約290日後）
- **形が長く残る理由**：原余韻が世界全体で物を最低限支えているため、名前・意味・用途が失われても、形は一年近く残る。ただし原余韻は記憶度を回復させず、忘れられていく流れも止めない。
- **汲み尽くした場合**：知る者の記憶も記録も引き綱を根にしているため、余韻を汲み尽くして綱を引き抜くと、すべての憶縁が同時に力を失う。覚えている者がいても、その記憶はもう出来事を指さない。そこから生まれた物も忘れられはじめる。
- **余韻が自然に消えきった場合**：綱は先にほどけているので、ほかの憶縁は傷まず、出来事は覚えられたままである。
- **ふたたび覚えられた場合**：憶縁が戻れば、忘れられていく流れは止まる。ただし、一度失われた名前や意味は、元どおりには戻らないことがある。

# 反復の余韻：常余韻（じょうよいん）
- 毎日・毎周期くり返される出来事は、一回ごとの余韻は小さいが、同じ形の余韻が重なり続ける。
- 毎日1単位ずつ加わり、毎日 2^(-1/29)（約0.976）倍に薄れるので、量は一日分のおよそ42倍で落ち着く（立ち上がりは約29日で半分、約87日で約9割に達する）。
- これを「常余韻」と呼ぶ。大事件の余韻より薄いが、決して涸れず、原余韻に次いで世界を満たす安定した魔力。
- 常灯の常余韻は、熱（灼）と移動（流）の出来事を含むため、灼・流の性質がおもに強い。ほどき月・留め月の満ち欠けも周期的な出来事で、同様の常余韻を生む。
- 汲んで元の出来事の記憶が薄れても、毎日新しい出来事が起きて余韻が補われるため、常余韻は汲み尽くせない（原余韻ほど無尽蔵ではなく、一度に大量に汲めば一時的に薄くなるだけ）。
- 毎日起きる出来事は毎日誰かの目に触れるため、憶縁を失わない。くり返されるものは忘れられにくい。
- 繰り返しが途絶えた場合（灯が昇らない日が生じた場合など）、常余韻は29日ごとに半分に薄れていく。

# 引き綱と代償（神託により明らかにされた仕組み）
- **引き綱（ひきづな）**：出来事が起きると、その余韻は目に見えない綱で元の出来事とつながる。出来事を知る者の記憶も、石碑や書物などの記録も、この綱を根にして鮮やかさを保っている。余韻そのものも憶縁の一つだが、ほかの憶縁の根でもある。
- **汲むとは**：綱を張ったまま余韻を引き抜くこと。綱が強く引かれ、その先につながる記憶や記録の鮮やかさも一緒に持っていかれる。
- **誰が忘れるか**：術者だけではなく、その出来事を知るすべての者。距離は関係ない。体験した者ほど深く、伝え聞いただけの者ほど浅く薄れる。
- **記録への影響**：石碑や書物の文字は消えない。しかし読んでも実感が結ばれなくなり、汲まれるほど「読めるのに分からない文字」に近づく。記録は人の記憶より持ちこたえる。
- **どれだけ忘れるか**：薄れる量は「汲んだ量 ÷ その出来事の余韻全体の量」で決まる。大事件の余韻を少し汲んでも影響は小さいが、小さな出来事の余韻は少し汲むだけで多くが失われる。
- **失われる順番**：感情 → 細かな経緯 → 名前・意味（あいまいになる）→ 汲み尽くすと、その出来事を指す力そのもの。
- **抜け跡（ぬけあと）**：汲み尽くされた出来事のあとに残る「何かがあったはずだ」という空洞。知る者も記録も、その出来事を指せなくなる。
- **自然に薄れる場合との違い**：月日とともに薄れる余韻は、先に綱をほどいてから空や地に溶けていく。綱がほどけているので、記憶も記録も傷まない。余韻が消えきっても、ほかの憶縁が残っていれば、出来事は覚えられたまま。
- **沈んだ余韻**：地に沈んだ余韻は薄れない。大きな出来事ほど沈んで憶石となり、人々が皆忘れたあとも、世界のほうがその出来事を覚え続ける。

# 憶石と巻き綱（神託により明らかにされた仕組み）
## 一、沈んだ余韻と綱
- 余韻が地に沈むとき、引き綱は切れない。綱は余韻とともに石の内側へ固く巻き取られ、「巻き綱（まきづな）」となる。
- 沈んだ余韻は薄れないため、巻き綱もほどけない。自然に薄れる余韻は綱をほどいてから溶けるが、沈んだ余韻にはその過程が起きない。
- 憶石はその出来事の憶縁であり、もっとも長く残る憶縁である。「世界のほうが出来事を覚え続ける」とは、巻き綱が残り続けることをいう。
- 一つの出来事の余韻が沈むと、いくつもの憶石に分かれることがある。同じ出来事に綱がつながる石どうしを「同根石（どうこんせき）」と呼ぶ。同根石は一本の綱を分け合っている。

## 二、憶石を燃料として使うとき
- 石から余韻を引くことを「焚く（たく）」という。巻き綱が引かれるので、代償の則はそのまま働く。出来事を知るすべての者の記憶が薄れ、記録は「読めるのに分からない文字」に近づく。
- 薄れる量は、ふつうの余韻と同じく「引いた量 ÷ その出来事の余韻全体（空にある分＋すべての同根石の分）」で決まる。
  - 空の余韻は月日とともに綱をほどいて薄れるため、時が経つほど全体に占める石の割合が大きくなる。古い出来事の石ほど、同じ量を焚いたときに失われる記憶が多い。創世から1年を過ぎた出来事では、全体のほぼすべてが石の分と考えてよい。
- **失われる順番が逆になる**：巻き綱は出来事の芯（名前・意味）に絡みついているため、石を焚くと「名前・意味 → 細かな経緯 → 感情」の順に薄れる（ふつうの余韻は「感情 → 経緯 → 名前・意味」）。
- その結果、何についての思いか分からない感情だけが残ることがある。これを「名無しの情（ななしのじょう）」という。
- **あふれにくさ**：石の余韻は表面から少しずつしか出てこないため、器を超えて一度にあふれることが少ない。器の小さい者でも大きな出来事の力を扱えるのが、憶石が燃料として重んじられる理由である。そのかわり、急いで大量に引くことはできない。
- 相の一致はそのまま働く。赤橙の石からは灼の現象しか起こせない。
- **無色の憶石**：創世のころに沈んだ無色の憶石の綱は、すべて最初の一打につながる。最初の一打の余韻（原余韻）は尽きないため、焚いて失われる記憶はごくわずかである。ただし相に分かれていないので、濁りよりもさらに扱いが難しい。

## 三、誰も覚えていない出来事の石
- 知る者も記録もない出来事では、憶石が最後の憶縁である。同根石が一つでも残っていれば、その出来事と、そこから生まれた物の記憶度は1に保たれる。
- 焚いても忘れる者はいない。引き抜かれた鮮やかさは行き場を失い、焚く者の胸を一瞬だけ通り抜けて散る。見知らぬ景色・声・温度が浮かんではすぐに消えるこの現象を「石語り（いしがたり）」という。
- 石語りで見たものは、綱がさらに引かれていく最中の幻なので、憶縁として根づかない。半日ほどで薄れる。
- 同根石の最後の一つを使い切ると、出来事は汲み尽くされたことになり、抜け跡となる。その出来事から生まれた物（地形・生き物の系統など）は最後の憶縁を失い、忘れられていく順番（名前→意味→用途→形）をたどりはじめる。古い石は安く見えて、高くつく。

## 四、使い切ること・砕くことと抜け跡
- **使い切る**：一つの石を焚き尽くすと、その石が担っていた分の記憶が、上の順番どおりに失われる。同根石がほかに残っていれば、出来事は薄れても抜け跡にはならない。空の余韻も含めて最後の一片を焚き尽くしたときだけ、抜け跡となる。
- **砕く**：石を砕くと、巻き綱が引かれずに断ち切られる。その石が担っていた分の記憶は、順番を踏まずに一度に失われる（感情も名前も同時に消える）。最後の同根石を砕けば、出来事は即座に抜け跡となる。
- **根無し余韻（ねなしよいん）**：砕いた石からこぼれ出た、綱を持たない余韻。もう出来事とつながらないので、汲んでも代償はない。憶縁にもならない。
  - 地に結びつく足がかりがないため沈まず、約3日ごとに半分に散る。相はもとの石と同じ。
  - 代償をまとめて先に払い、その見返りに短いあいだだけ自由な力を得る、という使い方になる。
- 砕かれた石のあとには、手ざわりのない空洞のような感覚が残る。これは抜け跡の小さな写しであり、「割れ跡（われあと）」と呼ぶ。

# 物になる余韻と石になる余韻（謎-001への答え）
- **凝形（ぎょうけい）**：同じ相の余韻が一つの場所に、空や地へ溶けていくより速く集まり続け、一定の濃さを超えると、余韻は自らの重なりで形をとり、物（水・岩など）になる。これを凝形という。
  - 凝形した物の余韻は、引き綱を張ったまま外に出ている。巻き取られていないので、ほかの余韻と同じく約29日ごとに半分に薄れ、補いがなければ消えていく。
  - 海は常灯の常余韻に、素岩は尽きない原余韻（最初の一打の余韻）に支えられているので、形を保ち続ける。
- **沈殿**：余韻が動きを止め、留め月の引きを受けて地に沈むと、綱は石の内側に巻き取られて巻き綱となり、憶石になる。
- まとめると、余韻が「動きながら集まる」と物になり、「止まって沈む」と憶石になる。物になった余韻も、動きを止めて沈めば憶石へ移ることがある（澱み瀬の青床がその例）。

# 五相の凝形（謎-012への答え）
- どの相の余韻も、一か所に空や地へ溶けるより速く集まり続ければ凝形して物になりうる。物の性質は相で決まる。
  - 灼：熱を内に抱く赤橙の岩（熾岩）。
  - 流：水（海・川）。
  - 結・別・生：それぞれ固有の物になりうるが、まだその例はない。
- 凝形には「絶え間ない補い」が要る。毎日くり返される出来事の常余韻か、尽きない原余韻だけがこの条件を満たす。いま世界で絶えず補われているのは、常灯がもたらす灼・流と、原余韻（無色）だけである。そのため凝形した物は、水（流）・素岩（無色）・熾岩（灼）の三つに限られる。
- 結・別・生の余韻は大隆起のような一度きりの出来事からしか生まれていないので、集まり続けることがなく、止まって沈んで憶石になる。これらの相がくり返し生まれる出来事が起きるようになれば、凝形する場所が現れると考えられる。
- 灼は軽く散りやすいため、ふつうは凝形する前に空へ散る。風が届かず、朝灼が毎日そそぐ閉じた窪地（熾窪）でだけ、散るより速くたまる。
- 熾岩は綱を張ったままの物なので、海と同じく日々の朝灼の補いで形を保っている。補いが止まれば、ひと月ほどで半分ずつ薄れていく。
