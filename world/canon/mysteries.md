# 未解決の謎
この世界でまだ答えの出ていない問い。創造や時代の節目で、ふさわしい時に答えが明かされる。

## 解き明かされた謎
- **謎-002**：海水も流の余韻からできているのなら、月日とともに薄れていくのか。毎日の補いとの釣り合いはどうなっているのか。
  - → 海水も流の余韻なので約29日ごとに半分に薄れるが、毎日の補いと釣り合い、一日分のおよそ42倍の量で落ち着く。それまでは海が満ち続け（創世海進）、薄れた分は余霞・還り雨・川を経て空と地に溶ける。（解決：創世暦1年 薄霞 8日）
- **謎-001**：余韻が憶石になる場合と、素岩や海水のような物になる場合とでは、何が違うのか。
  - → 余韻が動きながら一か所に集まり続けると自らの重なりで物の形をとり（凝形）、綱を張ったまま薄れていく。動きを止めて地に沈むと綱が巻き取られて憶石になる。（解決：創世暦1年 薄霞 20日）
- **謎-006**：留め月の満ちで沈みやすくなる流の余韻のうち、海や川の水から青灰色の憶石になる分はあるのか。あるなら、それは海の量を減らすのか。
  - → 水が止まっている所（凪海の澱み瀬）でだけ、海の流の余韻が沈んで青灰色の憶石（青床）になる。そのぶん海の落ち着く量は減るが、差は海全体の約0.3%にすぎない。（解決：創世暦1年 薄霞 20日）
- **謎-012**：灼・結・別・生の相の余韻も、一か所に集まり続ければ凝形して固有の物（熱い岩、黒い土など）になるのか。
  - → どの相も絶え間ない補いがあれば凝形するが、いまそれを満たすのは常灯の灼・流と原余韻だけ。灼は風の届かない熾窪でだけ凝形して熱を抱く赤橙の熾岩となり、一度きりの出来事にしか生まれない結・別・生はまだ憶石として沈むのみである。（解決：創世暦1年 薄霞 26日）
- **謎-007**：日の出・日の入りは世界で一度ずつの出来事なのか、土地ごとに別の出来事なのか。余韻が東ほど・西ほど濃くなるのは、出来事に『起きた場所』があるということなのか。
  - → 一日の日の出・日の入りは世界でそれぞれ一度きりの出来事だが、起きた場所を持ち、その場所は光の縁（明け際・暮れ際）として東の果てから西へ渡っていく。光がはじける勢いは始まりで最も強いので朝灼は東ほど濃く、去る動きは西へ強まるので夕流は西へ集まる。（解決：創世暦1年 芽吹 3日）
- **謎-009**：動いている流の余韻は沈みにくいとすると、川底や波の荒い海の下には、ほかの相の憶石だけがたまっていくのか。
  - → 動く水の下では憶石はその場で育たず、よそで生まれて運ばれた流れ石と砕けた素岩の粒が積もる。流れ石は擦れて削れるたびに小さく砕かれ、根無し余韻をこぼす。（解決：創世暦1年 芽吹 9日）
- **謎-005**：川が海に還って海の余韻の一部になるなら、雨と川の分だけ海の落ち着く量は一日分の42倍より大きくなるのではないか。
  - → 雨と川の流れも新しい流の出来事なので、川が海に還る分だけ海は大きくなり、一日分のおよそ43.5倍で落ち着く。渚が進む距離もわずかに延びる。（解決：創世暦1年 芽吹 9日）
- **謎-013**：別れの裂け目の別の余韻は大隆起の一度きりの出来事から生まれたものだが、墨砂を支え続けるほどの補いは、いま何から来ているのか。
  - → 裂け目の別の余韻が音を断つこと自体が裂ける出来事となり、新しい別の余韻を生む（音断ち）。昼夜落ち続ける還り川の滝の轟きなどが絶えず断たれ、別は常余韻のように補われ続けている。（解決：創世暦1年 芽吹 21日）
- **謎-015**：墨砂や音無し潮が音を吸うとき、音（響き）という出来事の余韻はどうなり、どの相に属するのか。
  - → 音は震えが伝わって動く出来事なので流の相に属する。吸われると音はそこで終わり、流の余韻は伝わった分だけ小さく残る。断たれることそのものが、別の相の新しい余韻を生む。（解決：創世暦1年 芽吹 21日）
- **謎-008**：霜の凍りと溶けのように土地ごとにくり返される小さな出来事の常余韻は、どの相を持ち、海や地形をつくるほど積もることがあるのか。
  - → 霜の凍りは結、解けは流の相の常余韻を生む。霜帯では結が毎日補われるが、沈む速さがまさるので凝形はせず、岩肌に一夜ごとの薄い白い憶石（霜石）を重ねるだけで、海や地形をつくるほどにはならない。（解決：創世暦1年 芽吹 27日）
- **謎-017**：海の上に落ちた朝灼（灼の余韻）は流の海水と混ざって濁りになるのか、それとも湯気として空へ散るだけなのか。
  - → 海に落ちた朝灼は、相が違うため流の海水と混ざっても濁りにならない。熱として海面にしばらく抱えられて海を温め、やがて湯気とともに空へ散る。（解決：創世暦1年 灯守 4日）
